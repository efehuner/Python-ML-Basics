# 🚀 Machine Learning & Python Journey

Welcome to my Machine Learning diary! 📖 

This repository is a growing archive of my daily Python and Machine Learning practice scripts. Rather than a single application, it contains independent scripts (currently 35+ scripts) where I implement algorithms, test concepts, and document my daily progress from basic data manipulation to workflow automation.

## 🛠️ Technologies
- **Language:** Python 3
- **Libraries:** Scikit-Learn, XGBoost, LightGBM, Pandas, NumPy, Matplotlib, Seaborn, Joblib, Streamlit

- **Logistic Regression & Probability Estimation**
- **K-Nearest Neighbors (KNN) & Feature Scaling**
- **Decision Trees & Rule Extraction**
- **Random Forest & Ensemble Learning:** RandomForestClassifier
- **Ensemble Learning Comparison:** Random Forest vs Gradient Boosting (GradientBoostingClassifier)

- **Model Evaluation & Error Analysis:** Confusion Matrix, Precision, Recall, Classification Report

- **Cross-Validation & Model Validation:** cross_val_score
- **Support Vector Machines (SVM) & Kernel Trick:** linear, rbf
